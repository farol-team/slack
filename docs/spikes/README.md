# Spikes

Time-boxed investigations: what we went and looked at, what we actually saw,
and what it changes. A spike is not a plan and not a decision — it is the
evidence a decision can later be argued from, with a date on it so a reader
knows how stale it is.

House rules, so these stay worth reading:

- **Separate what was observed from what was concluded.** Every claim about
  someone else's product says how we know it — page read, repo cloned, code
  file named. Inference is labelled as inference.
- **Date everything.** Competitors ship. A spike is a photograph, not a map.
- **Say what it changes.** A spike that ends without "so what" was a hobby.
- **No numbers without a source.** Marketing figures are quoted as marketing
  figures.
